Requisiti per configurare l'Atlante

Prima di procedere con la configurazione, è necessario preparare i seguenti elementi. Solo il dataset e il logo devono essere già pronti, gli altri elementi verranno configurati nei passaggi successivi.

📋 Nota: La documentazione completa è disponibile nel repository GitHub del progetto. Consulta la documentazione completa →
📋 Nota: I progetti che hanno usato Atlante prêt-à-porter:

  • LEDA (For an Atlas of Italian Ecological Literature) è il primo atlante della letteratura ecocritica italiana: uno strumento interattivo, che consente di visualizzare, interagire e ragionare sugli spazi di quei testi che hanno tematizzato in chiave critica il rapporto uomo-ambiente dagli anni 60 ad oggi.

    Vai all'Atlante → Vai alla Repository Github →

  • Il Progetto SASSI mappa la storia delle prime ascensioni sull'arco alpino, creando un atlante interattivo dell'alpinismo pionieristico dal XVIII al XX secolo.

    Vai all'Atlante → Vai alla Repository Github →

Elementi richiesti

1. Dataset Obbligatorio

Il dataset deve essere composto da due file TSV collegati tramite una colonna pivot:

  • locations.tsv - dati geografici con colonne Location e lat_long
  • references.tsv - riferimenti con colonna ID e colonna pivot

La colonna pivot condivide lo stesso nome in entrambi i file e permette di collegare i dati.

📄 Copia il template del dataset
2. Logo del progetto Obbligatorio

File immagine in formato PNG, SVG o JPG da utilizzare nell'interfaccia del progetto. Dimensioni consigliate: 200x200px o rapporto 1:1.

📦 Setup Iniziale

  1. 1

    Scarica lo zip

    Oppure clona la repository da GitHub:

    git clone https://github.com/username/repository-name.git
  2. 2

    Estrai e posiziona i file

    Estrai lo zip e copia i contenuti nella cartella del progetto (in particolare la cartella public/ e il file tailwind.config.js)

  3. 3

    Configura l'ambiente

    Modifica il file .env.production con il nome della tua cartella/repository

  4. 4

    Installa le dipendenze

    Esegui lo script di setup per il tuo sistema operativo:

    Windows:

    setup.bat

    Mac/Linux:

    ./setup.sh

💻 Sviluppo Locale

Avvia il server di sviluppo:

npm start

L'app sarà disponibile su porta 5173 (o 5174 se già occupata)

Testa la versione di produzione:

npm run build npm run preview

Verrà creata la cartella dist/ con i file ottimizzati

🚀 Deployment su GitHub Pages

  1. 1

    Configura il repository remoto

    Imposta l'origin dalla tua repository GitHub:

    git remote add origin https://github.com/username/repository-name.git

    ⚠️ Importante: Il nome della repository deve essere lo stesso dichiarato in .env.production

  2. 2

    Rendi pubblica la repository

    Nelle impostazioni di GitHub, imposta la repository su Public per abilitare GitHub Pages

  3. 3

    Primo commit

    Carica tutti i contenuti dell'app sul branch main:

    git add . git commit -m "Initial commit" git push -u origin main

    Il .gitignore esclude automaticamente node_modules/ e dist/

  4. 4

    Deploy automatico

    Esegui il comando di deployment:

    npm run deploy

    ✅ Verrà creato automaticamente un branch gh-pages con la versione ottimizzata dalla cartella dist/

✅ Tutto pronto! Clicca sul pulsante per scaricare il tuo progetto.
